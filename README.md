## 배포 전 확인

`demo/lesson1.html` 맨 아래 `SCRIPT_URL`에 Apps Script 웹앱 주소(`.../exec`)를 넣어야
데모에서 제출한 응답이 구글시트에 쌓입니다.

```js
var SCRIPT_URL = "PASTE_WEBAPP_URL";   // ← 여기를 /exec 주소로 교체
```

## 구조

정적 HTML만 사용합니다. 빌드 과정이 없고 외부 라이브러리도 쓰지 않습니다.

- Node·npm 불필요
- 각 파일이 자기완결형 (CSS·JS 인라인)
- Vercel에서 설정 없이 바로 배포됨
