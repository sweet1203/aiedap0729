09:20–09:50 · 내 교과서·수업자료에서 학생 눈높이 요약을 만듭니다.

  1. notebooklm.google.com 접속 (구글 계정으로 바로 열립니다)

  3. 업로드가 끝나면 아래 프롬프트를 복사해 채팅창에 붙여넣기

⚠️ 내보내기(Export) 버튼을 찾지 마세요. NotebookLM에는 깔끔한 .md 내보내기가 없습니다. 채팅 답변을 복사하는 것으로 충분합니다.

2 AI로 코스웨어 만들기

09:50–10:35 · 템플릿의 ✏️ 자리를 내 교과 내용으로 채웁니다.

먼저 템플릿을 준비하세요

  1. 드라이브에서 01_코스웨어_템플릿.zip 다운로드
  2. 다운로드 폴더에서 압축 풀기 → 수업_템플릿.html, Code_복사용.txt 두 개
  3. 바탕화면에 내 이름 폴더를 만들어 옮기기 (예: 김다비_코스웨어)
  4. 수업_템플릿.html을 메모장이나 텍스트 편집기로 열기
    윈도우: 파일 우클릭 → 연결 프로그램 → 메모장 / 맥: 우클릭 → 다음으로 열기 → 텍스트 편집기
  5. Ctrl+A 전체 선택 → Ctrl+C 복사

💬 프롬프트 ② — 코스웨어 채우기 ★ 가장 중요

🚨 "단일 HTML 파일 하나로"를 꼭 넣으세요. 이걸 빼면 AI가 React 프로젝트나 여러 개 파일을 만들어줍니다. 그러면 4단계 배포에서 반드시 실패합니다.

💬 프롬프트 ③ — 정리 질문 4개 만들기

💬 프롬프트 ④ — 수업목표 3분할 (산출물에 그대로 씁니다)

✅ 이 3가지는 수업지도안(붙임5)에 그대로 들어갑니다. 나중에 다시 안 만들어도 됩니다.

받은 코드를 저장하고 확인하기

  1. AI가 준 HTML 코드를 전체 복사
  2. 메모장에 붙여넣고 다른 이름으로 저장
  3. 파일 이름: index.html · 파일 형식: 모든 파일 · 인코딩: UTF-8 (index.html로 저장해야 배포 주소에서 바로 열립니다)
  4. 저장한 파일을 더블클릭 → 브라우저에서 내 코스웨어가 열립니다 🎉
⚠️ 저장할 때 인코딩을 UTF-8로 하지 않으면 한글이 깨집니다.

3 구글시트 연결하기 ⚠️

10:45–11:35 · 오늘 가장 까다로운 단계입니다. 강사와 함께 천천히 진행합니다.

🚨 이 단계에서 "안전하지 않음" 경고 화면이 나옵니다. 정상입니다. 내가 직접 만든 스크립트라서 구글이 습관적으로 띄우는 경고예요. 아래 순서대로 진행하세요.

① 구글시트와 스크립트 만들기

  1. drive.google.com → 새로 만들기 → Google 스프레드시트
  2. 제목을 정하기 (예: 과학 수업응답)
  3. 메뉴 확장 프로그램 → Apps Script 클릭
  4. 기본으로 있는 코드를 전체 선택(Ctrl+A) 후 삭제
  5. 1단계에서 압축 푼 Code_복사용.txt를 메모장으로 열어 전체 복사 → 여기에 붙여넣기
  6. 저장 (💾 아이콘 또는 Ctrl+S)
⚠️ 01번 ZIP 안의 Code_복사용.txt를 구글 문서로 열지 마세요. 따옴표가 자동으로 바뀌어 코드가 깨집니다. 압축을 푼 뒤 메모장/텍스트 편집기에서 바로 복사하세요.

② 권한 승인 (놀라지 마세요)

  1. 상단 함수 목록에서 setup 선택 → ▶ 실행
  2. 권한 검토 창 → 내 구글 계정 선택
  3. ⚠️ "Google에서 확인하지 않은 앱" 경고가 뜹니다 → 고급 클릭
  4. 맨 아래 "(안전하지 않음)으로 이동" 클릭
  5. 허용 클릭
  6. 시트에 응답 탭이 생기면 성공 ✅

③ 웹 앱으로 배포하고 주소 받기

  1. 오른쪽 위 배포 → 새 배포
  2. 왼쪽 톱니바퀴 ⚙️ → 웹 앱 선택
  3. 실행 사용자: 나
  4. 액세스 권한: 링크가 있는 모든 사용자 ← 꼭 이걸로!
  5. 배포 클릭 → 권한 승인
  6. 웹 앱 URL 복사 — 주소가 /exec로 끝나는지 확인!
✅ 복사한 주소 예시: https://script.google.com/macros/s/AKfy...../exec
🚨 /dev로 끝나면 안 됩니다. 반드시 /exec여야 학생 응답이 들어옵니다.

④ 주소를 내 코스웨어에 넣기

  1. index.html(내가 저장한 코스웨어)을 메모장으로 열기
  2. Ctrl+F로 PASTE_WEBAPP_URL 찾기
  3. 그 부분을 복사한 /exec 주소로 교체 (따옴표 "는 그대로 두기)
  4. 저장
🆘 여기서 막히면 손드세요. 강사가 미리 만들어 둔 시트를 대신 드립니다. 그 주소를 받아서 ④번부터 이어가면 됩니다. 아무도 여기서 멈추지 않습니다.

4 인터넷에 올리기 (배포)

11:35–12:00 · 내 코스웨어에 주소(URL)를 만들어 줍니다.

① GitHub에 파일 올리기

  1. github.com 로그인 → 오른쪽 위 + → New repository
  2. 이름 입력 (예: my-courseware) · Public 선택 · Create repository
  3. uploading an existing file 링크 클릭
  4. 내 index.html을 드래그해서 올리기 (파일 하나면 됩니다)
  5. 아래 Commit changes 클릭
💡 commit(커밋)은 "이 상태로 저장해줘"라는 뜻입니다. 나중에 되돌릴 수도 있어요.

② Vercel로 배포하기

  1. vercel.com → GitHub 계정으로 로그인
  2. Add New → Project
  3. 방금 만든 저장소 옆 Import 클릭
  4. 아무 설정도 건드리지 말고 Deploy 클릭
  5. 잠시 기다리면 🎉 축하 화면 → 주소를 클릭하면 내 코스웨어!
🚨 설정 화면에서 아무것도 바꾸지 마세요. 그냥 Deploy만 누르면 됩니다.

정상입니다. 드라이브는 HTML을 미리보기 못 합니다. 다운로드한 뒤 더블클릭하세요.

"Google에서 확인하지 않은 앱"이라고 경고가 떠요

정상입니다. 내가 만든 스크립트라 뜨는 경고예요.
고급 → (안전하지 않음)으로 이동 → 허용을 누르면 진행됩니다.

제출했는데 구글시트에 안 들어와요
  1. 웹 앱 액세스 권한이 "링크가 있는 모든 사용자"인지 확인
    (배포 → 배포 관리 → 편집 ✏️)
  2. 코스웨어의 주소가 /exec로 끝나는지 확인 (/dev 아님!)
  3. 주소를 바꾼 뒤 저장했는지, GitHub에 다시 올렸는지 확인
"⚠️ 아직 제출 주소가 설정되지 않았어요"가 떠요

코스웨어 안의 PASTE_WEBAPP_URL을 실제 /exec 주소로 바꾸지 않았거나, 바꾼 뒤 저장을 안 한 상태입니다. 3단계 ④번을 다시 확인하세요.

배포했는데 흰 화면이거나 글자가 깨져요
  1. 파일 이름이 index.html이 맞는지 (한글·공백·대문자 없이)
  2. 저장할 때 인코딩을 UTF-8로 했는지 (한글 깨짐의 원인)
  3. AI가 코드를 바꾸며 구조를 깨뜨렸을 수 있음 → 프롬프트 ⑤로 복구
Vercel에서 배포가 실패해요 (빌드 에러)

AI가 React나 여러 개 파일을 만들어줬을 가능성이 큽니다. package.json 같은 파일이 있으면 Vercel이 설치를 시도하다 실패합니다.
→ 프롬프트 ②를 다시 쓰되 "단일 HTML 파일 하나로만"을 강조하세요.

GitHub에 어떻게 올리는지 모르겠어요

저장소를 만든 뒤 "uploading an existing file" 링크를 클릭하고, 파일을 드래그해서 놓으면 됩니다. 아래 Commit changes를 누르면 완료입니다.

수정했는데 사이트에 반영이 안 돼요

GitHub에 수정된 파일을 다시 올려야 합니다. 저장소에서 파일 클릭 → 연필(✏️) 아이콘 → 수정 → Commit changes. Vercel이 자동으로 다시 배포합니다.

AI가 준 코드가 너무 길어서 복사가 안 돼요

AI에게 "설명 없이 코드만 주세요"라고 하면 짧아집니다. 또는 "코드 블록으로 한 번에 주세요"라고 요청하고 코드 블록 우측 상단의 복사 버튼을 쓰세요.
